## [全球首款侵入式脑机接口医疗器械在中国获批上市](https://t.me/zaihuapd/42515) ⭐️ 9.0/10

中国国家药监局批准了博睿康医疗科技（上海）有限公司研发的"植入式脑机接口手部运动功能代偿系统"创新产品注册申请，标志着国际上首个侵入式脑机接口医疗器械正式进入临床应用阶段，实现全球首发上市。 此次获批是神经科技领域的历史性里程碑，是全球首个获得正式临床应用监管批准的侵入式脑机接口医疗器械。它为脊髓损伤瘫痪患者开辟了全新的治疗途径，有望彻底改变康复医学领域，并确立中国在脑机接口商业化方面的领先地位。 该产品采用硬脑膜外微创植入与无线供能通信技术，在不接触大脑组织、不损伤神经细胞的前提下获取脑电信号。它专为 18 至 60 岁因颈段脊髓损伤导致四肢瘫痪的患者设计，通过气动手套辅助实现手部抓握功能，临床试验结果显示受试者手部抓握能力显著提升，生活质量得到改善。

telegram · zaihuapd · 7月12日 14:39

**背景**: 侵入式脑机接口（BCI）是一种通过微创开颅手术将电极植入大脑皮层或硬膜外，直接采集原始神经电信号的技术，信号分辨率可达亚毫米级别。与非侵入式脑机接口使用头皮电极不同，侵入式脑机接口能提供更高的信号质量，但存在感染风险和生物相容性等挑战。硬脑膜外植入是一种半侵入式方法，将电极放置在大脑外的硬脑膜上，避免直接接触神经组织同时仍能获得高质量信号。该技术主要应用于医疗康复领域，帮助运动功能障碍患者通过脑电信号控制外部设备。

## [网络流量分析揭示 Grok Build CLI 将完整仓库上传至 xAI](https://gist.github.com/cereblab/dc9a40bc26120f4540e4e09b75ffb547) ⭐️ 8.0/10

一项针对 xAI Grok Build CLI 的网络流量层面分析揭示，该工具会将仓库的完整内容——包括每个被跟踪的文件和完整的 git 历史——上传至 xAI 服务器。关键在于，这种数据传输与 AI agent 在操作过程中实际读取或访问的内容无关。 这一发现引发了使用 AI 编程助手的开发者对隐私的严重担忧，因为专有源代码、提交历史以及潜在的敏感信息可能在未经明确同意或知晓的情况下被传输。它凸显了更广泛的行业风险：LLM 提供商的原生 AI 编程工具运行器可以在任何更新中悄然改变其数据收集行为。 上传范围并不局限于 agent 交互的文件；相反，无论 agent 实际使用了什么，所有被跟踪的文件以及完整的 git 历史都会被传输。这是通过网络层数据包检查而非文档审查发现的，意味着这种行为可能并未向用户透明披露。

hackernews · jhoho · 7月12日 01:09 · [社区讨论](https://news.ycombinator.com/item?id=48877371)

**背景**: Grok Build 是 xAI 的基于命令行的 AI 编程 agent，目前处于测试阶段，旨在通过终端界面帮助开发者完成代码生成、规划和开发工作流等任务。它是 LLM 提供商不断增长的原生 AI 编程工具生态系统的一部分，与 Anthropic 的 Claude Code 和 OpenAI 的 Codex CLI 等竞争对手并列。网络流量层面的分析涉及在数据包层面检查实际的网络流量，以确定应用程序具体发送和接收了哪些数据，这可以揭示供应商未记录或未披露的行为。

## [GPT-5.6 不到一小时证明困扰数学界 50 年的图论猜想](https://www.qbitai.com/2026/07/447873.html) ⭐️ 8.0/10

假设的 GPT-5.6 Sol Ultra 模型据称在不到一小时内完成了存在约半个世纪的循环双覆盖猜想证明，并生成了一份 3 页的 PDF。该模型通过 64 个子 agent 并行处理，将问题转化为有限域上的边标号和线性方程组问题，OpenAI 同时公布了约 700 个英文字符的完整 Prompt。 如果实现，这将成为 AI 辅助数学研究的分水岭时刻，证明多智能体大语言模型架构能够攻克困扰人类数学家数十年的深层开放性问题。它还展示了提示词工程的范式转变——通过明确验收标准和约束条件而非固定解题步骤——这可能彻底改变复杂推理任务委派给 AI 系统的方式。 循环双覆盖猜想由 Szekeres（1973 年）和 Seymour（1979 年）独立提出，断言每个无桥图都存在一个由简单圈组成的多重集，使每条边恰好被覆盖两次。模型的方法是在有限域上为每条边分配两个标签，使相同标签的边构成圈，从而将组合问题有效地转化为求解线性方程组。公布的 Prompt 刻意避免规定固定解题步骤，而是明确定义验收标准、边界条件和失败情形，同时要求动态分配子 agent 并设置独立审查，以检查证明是否偷换定义或遗漏情况。

telegram · zaihuapd · 7月12日 03:49

**背景**: 循环双覆盖猜想是图论中最著名的开放性问题之一，自 20 世纪 70 年代提出以来一直未被证明。无桥图是指删除任何一条边都不会使其断开的连通图，即每条边都至少属于一个圈。多智能体 AI 系统部署多个自主或半自主的 agent，并行协作处理子任务，从而可以同时探索不同的证明策略。提示词工程是通过精心设计自然语言指令来引导大语言模型产生预期行为的实践，本场景展示的是一种基于约束而非逐步程序的提示方法。
