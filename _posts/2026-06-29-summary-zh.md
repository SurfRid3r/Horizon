## [美国最高法院裁定地理围栏搜查令受宪法第四修正案保护](https://www.theguardian.com/us-news/2026/jun/29/supreme-court-geofence-warrants-case-decision) ⭐️ 9.0/10

美国最高法院已正式裁定，执法部门使用的高度侵入性地理围栏搜查令必须受到第四修正案宪法保护的约束。该裁决限制了警察在没有适当宪法保障的情况下从科技公司进行撒网式数据收集的能力。 这项具有里程碑意义的裁决对数字隐私和大规模监控产生了深远影响，确立了一项重大的法律范式转变，以保护公民免受过度侵入性的数字追踪。它还迫使科技公司重新评估其数据保留实践，从而为用户提供更好的隐私保护。 在 Chatrie 的具体案件中，Google 向执法部门提供了在一小时内距离银行抢劫案现场 150 米范围内的设备数据。此后，Google 已将其“位置历史记录”功能从集中式云存储转移到了设备端处理，专门为了最大程度地减少对此类广泛搜查令的配合。

hackernews · cdrnsf · 6月29日 15:54 · [社区讨论](https://news.ycombinator.com/item?id=48720924)

**背景**: 地理围栏搜查令（又称反向位置搜查令）允许执法部门要求科技公司（如 Google 的 Sensorvault）提供在特定时间段内位于特定地理区域内的所有活跃移动设备的数据。与要求针对特定嫌疑犯具有相当理由的传统搜查令不同，地理围栏搜查令执行的是一般性搜查，通常会捕捉到无辜旁观者的数据。第四修正案保护公民免受无理搜查和扣押，要求执法部门基于相当理由才能获得搜查令。

## [Progress Kemp LoadMaster 中发现严重的预认证 RCE 漏洞](https://labs.watchtowr.com/enterprise-tech-in-shell-out-progress-kemp-loadmaster-uninitialized-heap-to-pre-auth-rce-cve-2026-8037/) ⭐️ 9.0/10

watchTowr Labs 发布了一份技术深度分析报告，详细介绍了 Progress Kemp LoadMaster 中一个被追踪为 CVE-2026-8037 的严重预认证远程代码执行（RCE）漏洞。该漏洞源于未初始化的堆内存条件，允许未经身份验证的攻击者完全控制该设备。 负载均衡器通常位于企业网络的边缘，这意味着预认证 RCE 漏洞很容易成为攻击者入侵内部基础设施的初始入口。这一发现突显了边缘设备所面临的严重安全风险，并强调了各组织迫切需要修补其暴露的系统。 该漏洞利用程序专门利用未初始化的堆内存错误来实现未经身份验证的远程代码执行，从而有效绕过正常的身份验证屏障。watchTowr Labs 演示了原本旨在保护网络安全的边缘设备是如何变成被用来攻陷网络的网关的。

rss · watchTowr Labs - Blog · 6月29日 19:24

**背景**: Progress Kemp LoadMaster 是一款广泛使用的负载均衡器，旨在优化企业应用程序并保护网络边缘。未初始化的堆漏洞是指程序在分配内存后未能清除或设置初始值，这可能使攻击者能够利用残留数据来劫持执行流。预认证 RCE 是一种极其严重的漏洞类型，允许攻击者在进行任何登录或身份验证之前远程执行恶意代码。

## [HackerRank 开源 ATS 显示 LLM 简历评分极不一致](https://danunparsed.com/p/hackerrank-open-source-ats) ⭐️ 8.0/10

一位开发者对同一份简历运行了 HackerRank 的开源 ATS 评分工具 100 次，由于 LLM 的随机性，得到了从 74 到 90 不等的差异巨大的评分。项目评分的不一致性最为明显，而整体评分在更新后略有改善。 随着越来越多公司部署基于 LLM 的工具来自动化简历筛选和招聘决策，这暴露了一个关键的可靠性问题——不一致的评分可能导致合格的候选人被不公平地拒绝。这还引发了 AI 驱动的招聘歧视方面的潜在法律问题，尤其是在欧盟反歧视法下。 作者最初将 LLM 的温度参数设为 0.1，认为这会使输出接近确定性，但评论者指出即使低温也不能保证 LLM 的确定性行为——多模态模型仍可能对相同输入产生不同输出。HackerRank CTO 在 HN 讨论中澄清，该工具严格来说是一个招聘代理而非完整的 ATS。

hackernews · sambellll · 6月29日 01:44 · [社区讨论](https://news.ycombinator.com/item?id=48713832)

**背景**: 申请人跟踪系统（ATS）是雇主用于管理求职申请、筛选简历和简化招聘流程的软件。现代 ATS 工具越来越多地集成 LLM 来自动根据职位描述对候选人进行评分和排名，承诺在大规模应用中提升效率。然而，LLM 通过随机过程——即从学习到的概率分布中进行采样——来生成文本，这意味着即使在低温设置下，它们也可能对相同输入产生不同输出。

## [Miasma 蠕虫攻击在 105 秒内禁用微软 73 个 GitHub 仓库](https://mp.weixin.qq.com/s?__biz=MzkyMTI0NjA3OA==&mid=2247495259&idx=1&sn=adebb88353849918e5d284d45187fc02) ⭐️ 8.0/10

2026 年 6 月 5 日，一种名为 Miasma 蠕虫的供应链攻击在 105 秒内自动禁用了微软的 73 个 GitHub 仓库，其触发原因是一名开发者用 VS Code 打开了一个被污染的项目文件夹。该公开的攻击工具包主要通过 SessionStart 钩子注入 AI 编程工具，并利用 GitHub 提交搜索进行命令与控制（C2）操作。 此次事件凸显了开发者供应链中存在的严重漏洞，展示了本地系统被攻破后能够多快地演变为大规模的代码仓库被禁用。它暴露了广泛使用的开发环境和 AI 编程工具中的重大安全风险，威胁着全球软件开发管道的完整性。 Miasma 蠕虫专门针对包括 Claude Code 和 Copilot 在内的 13 种 AI 工具，利用零日漏洞（零 CVE）运行，并通过伪造 SLSA 溯源来绕过安全检查。它通过使用三个独立的 GitHub 提交搜索通道来建立命令与控制基础设施，每个通道都有不同的搜索字符串和用途。

rss · M01NTeam · 6月29日 10:00

## [长鑫存储与腾讯签署近 30 亿美元 DRAM 供应协议](https://www.reuters.com/world/china/chinas-cxmt-wins-3-billion-memory-supply-deal-with-tencent-sources-say-2026-06-29/) ⭐️ 8.0/10

中国 DRAM 制造商长鑫存储已与腾讯签署了一项价值近 30 亿美元的长期供应协议，为其提供服务器内存芯片。此外，据报道长鑫存储还在与阿里云、字节跳动和小米等其他科技巨头进行积极谈判。 这笔数十亿美元的交易标志着中国本土半导体行业的一个重要里程碑，意味着大规模云基础设施正转向本地化采购。通过将国产 DRAM 整合到大型数据中心中，中国科技企业可以大幅减少对外国内存供应商的依赖，并降低供应链风险。 该供应协议价值超 200 亿元人民币（约 29.4 亿美元），覆盖期为三到五年的服务器芯片供货。长鑫存储和腾讯均未对该交易的具体细节的置评请求作出官方回应。

telegram · zaihuapd · 6月29日 09:31

**背景**: 长鑫存储成立于 2016 年，总部位于合肥，是中国领先的本土一体化存储器制造商，致力于 DRAM 芯片的设计、研发和生产。DRAM（动态随机存取存储器）是计算领域的关键组件，允许按任意顺序快速读写数据，对高性能服务器运行至关重要。从历史上看，全球 DRAM 市场长期由外国公司主导，使得中国科技巨头高度依赖进口服务器内存。
