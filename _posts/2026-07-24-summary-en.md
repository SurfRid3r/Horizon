## [Cloudflare Reveals Widespread Manipulation of BGP ORIGIN Attributes](https://blog.cloudflare.com/bgp-origin-attribute/) ⭐️ 9.0/10

Cloudflare released in-depth testing results showing that transit providers rewrite the BGP ORIGIN attribute in almost 70% of internet paths to gain traffic routing advantages. Consequently, Cloudflare argues that the ORIGIN attribute should be deprecated from the BGP route selection process. This revelation highlights a fundamental flaw in the reliability of core internet routing protocols, affecting how traffic is directed across global networks. Deprecating the ORIGIN attribute could lead to updated networking standards and more predictable, secure internet routing behaviors. The BGP ORIGIN attribute is intended to indicate the origin of a routing update (IGP, EGP, or Incomplete) and is used as a tie-breaker in step 8 of the BGP best-path selection algorithm. Transit providers are improperly modifying this well-known mandatory attribute to manipulate inbound traffic, rendering it completely unreliable for its intended purpose.

rss · The Cloudflare Blog · Jul 24, 17:25

**Background**: BGP (Border Gateway Protocol) is the standard routing protocol that makes the internet work by exchanging routing information between different autonomous systems. To choose the best path among multiple options, BGP uses a strict decision process that evaluates various attributes. The ORIGIN code is a well-known mandatory BGP path attribute that specifies how a route was originally introduced into BGP, preferring IGP over EGP, and EGP over Incomplete.

## [Security Camera Shipped with Hardcoded GitHub Admin Token](https://hhh.hn/hanwha-github-token/) ⭐️ 8.0/10

A security researcher discovered that a commercial security camera from Hanwha shipped with a hardcoded GitHub administrative token directly embedded in its login page. Additionally, the firmware was found to contain hardcoded US Department of Defense IP addresses and other alarming insecure defaults. This incident highlights a severe supply chain and operational security failure, as an attacker could leverage the leaked token to access private source code or compromise backend infrastructure. It underscores the persistent lack of baseline security practices in the consumer IoT industry, putting user privacy and network safety at massive risk. The exposure of an administrative token on a publicly accessible login page means anyone scanning the device could immediately gain privileged access to the manufacturer's code repositories. Furthermore, baking static IP addresses and credentials directly into the firmware represents a significant engineering anti-pattern that cannot be mitigated without a manufacturer-issued patch.

hackernews · hhh · Jul 24, 11:54 · [Discussion](https://news.ycombinator.com/item?id=49034292)

**Background**: Hardcoded credentials are a common but critical vulnerability where developers leave sensitive keys, passwords, or tokens directly in the source code. IoT devices, such as security cameras, often process sensitive data and sit on local networks, making them attractive targets for malicious actors. Utilizing secure network segmentation, such as placing IoT devices on an isolated Virtual Local Area Network (VLAN) without internet access, is a standard defensive practice to mitigate such hardware flaws.

## [Flux 3 X Mimic: Video Generation Meets Robotics](https://bfl.ai/blog/flux-3-mimic) ⭐️ 8.0/10

Black Forest Labs introduced FLUX-mimic, a novel system that extracts a learned world representation from the FLUX video generation model to control robotic arms. By training a lightweight action decoder on intermediate features from the video prediction path, the model successfully performs complex physical tasks without requiring a specialized robotics architecture. This approach validates the theory that advanced multimodal video models inherently contain functional 'world models' that understand physics and material properties, which can be directly applied to robotic control. It opens a new, highly generalizable pathway for robotics that leverages internet-scale pretraining, potentially bypassing the need to collect massive datasets for specific physical tasks. FLUX-mimic utilizes a flow matching-based action decoder trained on top of the latent representations extracted from the video prediction path. While effective, the developers note that these representations can be 'less disentangled' compared to specialized approaches, which might place a ceiling on their usefulness for tasks requiring deep world understanding.

hackernews · kensai · Jul 24, 09:31 · [Discussion](https://news.ycombinator.com/item?id=49033127)

**Background**: In artificial intelligence, a 'world model' is a system that simulates dynamics like physics, object interactions, and causality, rather than merely classifying or generating outputs. Recent paradigms like Video-Action Models (VAMs), such as the 'mimic-video' project, leverage internet-scale video data to capture semantics and visual dynamics during pretraining. By isolating the task of low-level robotic control into a lightweight decoder, these systems aim to achieve generalizable robot control that goes beyond traditional Vision-Language-Action (VLA) models.
