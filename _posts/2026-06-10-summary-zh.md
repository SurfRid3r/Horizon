## [德国法院裁定谷歌对 AI Overviews 虚假信息负责](https://thenextweb.com/news/google-ai-overviews-german-court-liable) ⭐️ 9.0/10

## [PgDog 完成种子轮融资以解决 PostgreSQL 扩展问题](https://pgdog.dev/blog/our-funding-announcement) ⭐️ 8.0/10

用 Rust 编写的新型 PostgreSQL 代理和分片工具 PgDog 宣布已获得种子轮融资，以进一步开发其应对海量数据库吞吐量的解决方案。该工具将连接池、负载均衡和分片整合到一个单一的代理中，以帮助应用程序实现水平扩展。 这个消息很重要，因为大规模扩展 PostgreSQL 部署历来是一项重大的工程挑战，通常要求公司重写应用程序逻辑或转向 NoSQL 数据库。通过提供一个透明的分片和池化代理，PgDog 可以让企业在不更改应用程序代码的情况下水平扩展现有的 PostgreSQL 基础设施。 PgDog 使用 Rust 编写以确保高性能和安全性，并且它支持在分片之间自动生成单调的大整数主键。它还独特地支持分片键变更，允许用户仅使用标准的 UPDATE 语句在分片之间移动行。

hackernews · levkk · 6月10日 14:02 · [社区讨论](https://news.ycombinator.com/item?id=48476466)

**背景**: 随着数据库的增长，垂直扩展（为单台机器增加更多算力）最终会达到极限，这就需要通过分片等技术进行水平扩展（将数据分布在多台机器上）。然而，原生的 PostgreSQL 分片出了名的复杂，通常需要外部代理来路由查询、管理连接和分发数据，同时向应用程序呈现为单个数据库。

## [采用 HTML-first 架构使网站用户一夜翻倍](https://mohkohn.co.uk/writing/html-first/) ⭐️ 8.0/10

一位开发者成功为某个网络项目实施了 HTML-first 架构和渐进式增强，从而摆脱了对庞大的 JavaScript 依赖。这种架构上的转变极大地提升了可访问性和性能，直接促使该网站的用户数量在一夜之间翻倍。 这凸显了业界对复杂的 JavaScript 密集型单页应用的强烈抵制，转而青睐更简单的超媒体驱动方法。拥抱 HTML-first 设计不仅能提升 SEO 和 Core Web Vitals 性能指标，还能确保在不同设备和网络条件下为用户提供更广泛的访问性。 作者采用了一种即使在没有 JavaScript 的情况下网站也能完美运行的方法，完全依赖标准的 HTML 元素（例如标准输入组件和提交按钮）。社区中的开发者还指出，使用 HTMX、Go 和 SQLite 等轻量级技术栈也取得了成功，并通过 Cloudflare 缓存无缝处理了庞大的流量负载。

## [梅赛德斯-奔驰开始大规模生产电动轴向磁通电机](https://media.mercedes-benz.com/en/article/bebac2af-acdc-465a-9538-adb0bf3d8ccf) ⭐️ 8.0/10

梅赛德斯-奔驰已正式开始大规模生产紧凑轻便的电动轴向磁通电机，利用了其从 YASA 公司收购的技术。这标志着这种独特的“盘式”电机在汽车行业从理论优势向实际商业化部署的重大转变。 这一制造里程碑意义重大，因为与传统径向电机相比，轴向磁通电机具有更高的功率密度和更轻的重量，可以直接提高电动汽车的效率和续航里程。此外，其紧凑的尺寸为车辆空间布局提供了新的可能性，允许更宽敞的内饰设计或为更大的电池腾出空间。 在轴向磁通电机中，磁通方向与旋转轴平行，从而形成扁平的圆盘状，而不是长长的圆柱体。这种几何结构使得扭矩随转子直径的立方而增加，在给定体积内提供更好的散热管理和更高的扭矩密度。

## [Google 推出 DiffusionGemma：文本生成速度提升四倍](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/) ⭐️ 8.0/10

Google DeepMind 发布了 DiffusionGemma，这是一个拥有 260 亿参数的混合专家（MoE）模型，它利用扩散技术生成文本的速度比传统自回归模型快 4 倍。该开源模型采用 Apache 2.0 许可证，具有 256K 上下文窗口和多模态能力。 这一突破从根本上改变了文本生成的范式，极大地降低了推理延迟，从而实现了类似快速结对编程的高度交互式实时用户体验。此外，该架构为边缘设备带来了巨大的性能提升，而传统的自回归解码器在这些设备上通常面临批处理困难和计算资源闲置的问题。 该模型的工作原理是从一个完全被掩盖或充满噪声的序列开始，并在所有位置上同时对其进行迭代细化以生成连贯的文本，而不是逐个预测 token。尽管它在像单张 H100 这样的相同硬件上实现了惊人的速度，但早期讨论指出其能力可能略弱于标准的自回归 Gemma 模型。

hackernews · meetpateltech · 6月10日 16:09 · [社区讨论](https://news.ycombinator.com/item?id=48478471)

**背景**: 传统的 LLM（如 GPT-4 和 LLaMA）依赖于自回归解码，即严格按照从左到右的顺序生成文本，每次计算一个 token，因为每个新 token 都必须考虑之前所有的 token。相比之下，扩散语言模型（dLLMs）将图像生成中使用的概念应用于文本，从随机噪声开始并进行迭代去噪。这使得 dLLMs 能够在每一步中并行更新整个序列中的多个 token，从而显著加速生成过程。

## [Apple 推出 macOS 原生 Container Machines](https://github.com/apple/container/blob/main/docs/container-machine.md) ⭐️ 8.0/10

Apple 为 macOS 推出了“Container Machines”，这是一个使用虚拟机创建轻量级持久性 Linux 环境的新工具，由 Swift 编写并针对 Apple Silicon 进行了优化。该项目由 Docker 和 Containerd 的长期维护者、杰出工程师 Michael Crosby 领导开发。 此次发布为 Apple 生态系统提供了原生且高度优化的容器化解决方案，直接挑战了 Docker Desktop 和 OrbStack 等成熟的第三方开发者工具。它极大地简化了开发者在 macOS 上构建和测试 Linux 应用程序的工作流程。 容器机器不仅针对单一应用程序建模，而是模拟完整的 Linux 环境，允许运行镜像的 init 系统来处理长期运行的服务或在进程管理器下进行测试。虽然该工具可以在 macOS 15 上运行，但用户需要升级到 macOS 26 才能避免严重的网络限制（例如缺乏容器间通信）。

hackernews · timsneath · 6月10日 00:29 · [社区讨论](https://news.ycombinator.com/item?id=48469658)

**背景**: 传统上，在 macOS 上运行 Linux 容器需要像 Docker Desktop 这样的第三方应用程序，它们利用繁重的虚拟机来弥合操作系统的差异。开放容器倡议（OCI）为容器格式和运行时制定了供应商中立的行业标准，确保了跨不同平台的互操作性。Apple 的新框架利用其自研芯片的虚拟化能力，提供了更加集成且高性能的原生体验。
