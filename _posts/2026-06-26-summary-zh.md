## [OpenAI 预览 GPT-5.6 Sol：Cerebras 硬件上达每秒 750 token](https://openai.com/index/previewing-gpt-5-6-sol/) ⭐️ 9.0/10

OpenAI 预览了下一代前沿模型 GPT-5.6 Sol，同时推出的还有平衡型模型 Terra 和经济型模型 Luna。Sol 将于 2026 年 7 月起在 Cerebras 硬件上以高达每秒 750 个 token 的速度运行，初始访问权限仅限部分客户。 以每秒 750 个 token 的速度运行前沿模型，代表着推理速度的重大飞跃，可能重塑实时 AI 应用、智能体工作流和开发者体验。新的命名体系（Sol/Terra/Luna 表示规模层级）也表明 OpenAI 正努力简化其日益复杂的模型阵容，同时拓展与 Cerebras 等非传统硬件供应商的合作。 在新命名体系下，数字标识模型代次，Sol、Terra 和 Luna 标识规模层级：Sol 是旗舰版，Terra 被定位为性能与 GPT-5.5 相当但成本约减半，Luna 则是快速且经济实惠的选择。GPT-5.6 Sol 在编程、科学和网络安全方面具备更强能力，并配备 OpenAI 最先进的安全技术栈。

## [美国政府将为 OpenAI 的 GPT-5.6 模型审查用户访问权限](https://www.washingtonpost.com/technology/2026/06/26/openai-says-us-government-will-vet-users-its-latest-ai-model/) ⭐️ 9.0/10

## [苹果发布 Xcode 26.3，引入代理式编码并调整 SDK 要求](https://t.me/zaihuapd/42187) ⭐️ 9.0/10

苹果发布了 Xcode 26.3，新增了"代理式编码"功能，开发者可以在 IDE 内通过自然语言调用 OpenAI 和 Anthropic 的 AI 代理，自动理解项目、编写代码、构建应用、运行测试并修复错误。此外，苹果宣布自 2026 年 4 月 28 日起，提交至 App Store Connect 的应用和游戏必须使用 iOS 26、iPadOS 26、tvOS 26、visionOS 26 和 watchOS 26 的最新 SDK 进行构建。 这标志着大型科技公司首次在主流 IDE 中原生集成全自动化 AI 编程工作流，从根本上改变了苹果生态中开发者构建软件的方式。强制升级 SDK 的要求将迫使整个苹果开发者社区采用最新的工具和框架，确保平台一致性，但同时可能对现有的开发流程造成冲击。 代理式编码功能集成了 OpenAI 和 Anthropic 的 AI 代理，支持在 Xcode 内部自主完成代码生成、测试和调试，而无需依赖外部工具。SDK 强制升级要求涵盖五个平台，并设定了明确的截止日期，为开发者提供了有限的迁移窗口期。

telegram · zaihuapd · 6月26日 04:04

**背景**: 代理式编码代表了超越 GitHub Copilot 等传统 AI 代码补全工具的进化——不再仅仅是建议代码片段，而是自主 AI 代理可以在最少人工监督下规划、执行和迭代整个编程任务。这种范式转变在整个软件行业正获得越来越多的关注，OpenHands 等工具和各种 Agent 框架已经展示了端到端自动化开发工作流的潜力。苹果将这一能力集成到 Xcode 中，标志着代理式编码在企业级第一方开发环境中的主流化采用。

## [互联网年龄验证法律将严重摧毁在线隐私](https://expression.fire.org/p/the-papers-please-era-of-the-internet) ⭐️ 8.0/10

一篇发表在 expression.fire.org 上的评论文章指出，新兴的互联网年龄验证法律正在开启一个要求出示证件的时代，将严重损害在线隐私。文章警告用户将被迫提交政府身份证件才能访问在线内容，从而创建极易被滥用的大规模敏感个人信息数据库。 全球各国政府正在推行年龄验证强制令，在保护未成年人和保护所有互联网用户隐私之间制造了根本性的冲突。如果大规模实施，这些法律可能将基于身份的网络准入常态化，侵蚀匿名获取信息的权利，并使数百万人面临数据泄露、监控和胁迫的风险。 文章强调，当前的年龄验证方法通常要求用户上传护照等政府签发身份证件的照片，从而创建高度敏感数据的集中存储。匿名凭证等技术替代方案确实存在——它可以在不透露身份的情况下证明年龄等属性——但各国政府对采用隐私保护协议几乎没有任何兴趣。

hackernews · bilsbie · 6月25日 21:44 · [社区讨论](https://news.ycombinator.com/item?id=48679608)

**背景**: 年龄验证法律要求网站（尤其是托管成人内容或社交媒体的网站）在允许用户访问之前验证用户是否达到最低年龄门槛。包括英国、法国和美国多个州在内的多个司法管辖区已经通过或提出了此类立法，通常以保护儿童为框架。令人担忧的是，合规通常涉及收集和存储身份证件，从根本上改变了自互联网诞生以来一直存在的在线匿名性预期。

## [Amazon Q VS Code 扩展中的 MCP 自动执行漏洞可实现云端环境入侵](https://www.wiz.io/blog/amazon-q-vulnerability) ⭐️ 8.0/10

Wiz 研究人员披露了 Amazon Q VS Code 扩展中的一个漏洞：该工具会从工作区文件中自动加载 Model Context Protocol（MCP）服务器配置，而无需用户同意。攻击者只需构造一个恶意代码仓库，受害者执行 git clone 后即可触发远程代码执行，从而可能入侵其云端环境和敏感凭据。 该漏洞揭示了 AI 编程助手生态系统中的系统性风险：随着 MCP 等工具成为大语言模型与外部系统之间的标准桥梁，从不受信任的工作区文件中自动加载服务器配置会造成强大且隐蔽的攻击面。由于 Amazon Q 被 AWS 开发者广泛使用，克隆一个被投毒的代码仓库就可能导致整个云账户被攻陷。 该攻击链通过在项目工作区文件中嵌入恶意的 MCP 服务器配置来实现，当项目在 VS Code 中打开时，Amazon Q 会静默加载并执行这些配置。OX Security 和 Check Point 也独立发现了类似问题，表明 MCP 自动执行是一个行业范围内的普遍问题，而非 Amazon 独有的缺陷。

rss · Wiz Blog | RSS feed · 6月26日 12:00

**背景**: Model Context Protocol（MCP）是 Anthropic 于 2024 年 11 月推出的开放标准，旨在规范大语言模型等 AI 系统与外部工具、数据源和工作流之间的连接方式。Amazon Q 是 AWS 推出的 AI 驱动的编程助手，以 VS Code 扩展的形式提供，具备实时代码补全、错误检测和自然语言代码生成等功能。该漏洞的根本原因在于：MCP 服务器可以执行任意代码以与外部系统交互，而自动信任工作区级别的 MCP 配置则打破了不受信任的源代码与开发者本地环境之间的安全边界。

## [联邦语言模型微调中的隐私后门问题](https://paper.seebug.org/3493) ⭐️ 8.0/10

最近的一篇研究论文揭示了在多方利用联邦学习（FL）框架协作微调大语言模型（LLM）时出现的一个关键隐私后门漏洞。该研究展示了恶意攻击者如何利用这一协作过程破坏系统并提取敏感数据。 这一发现突显了 AI 训练流程中面临的重大安全风险，即使采用了专门为保护用户隐私而设计的联邦学习等架构也无法幸免。它直接影响了依赖协作微调的组织，并强调了在分布式 AI 生态系统中建立强大防御机制以防止数据泄露的紧迫性。 该漏洞专门针对联邦学习的工作流程，由于客户端数据的分散性和异构性，中央服务器难以验证本地模型更新的完整性。攻击者通过充当恶意客户端并在微调过程中注入恶意的模型更新，可以植入后门以提取其他参与者的私人信息。

rss · Seebug漏洞社区 · 6月26日 08:11

**背景**: 联邦学习是一种分布式机器学习技术，允许多个实体在不集中原始数据的情况下协作训练模型，旨在解决数据孤岛和隐私问题。客户端只需与中央服务器共享模型更新，而无需共享原始数据。然而，由于服务器无法轻易检查本地数据或完全验证每次更新背后的意图，FL 系统天生容易受到后门攻击。

## [三星与 SK 海力士拟宣布 6480 亿美元大规模 AI 投资](https://www.bloomberg.com/news/articles/2026-06-26/samsung-and-sk-hynix-prepare-huge-spending-increase-reports-say) ⭐️ 8.0/10

三星和 SK 海力士将于 6 月 29 日宣布聚焦半导体和 AI 基础设施的历史性投资计划。三星预计将公布价值 1000 万亿韩元（约 6480 亿美元）的破纪录十年支出方案，而 SK 海力士则计划在五年内将产能翻倍。 这两家韩国半导体巨头史无前例的财政承诺将从根本上重塑全球 AI 硬件供应链并加速数据中心的扩张。这标志着向物理 AI 和先进芯片制造的战略转变，巩固了它们在全球科技竞赛中的主导地位。 此次国家简报会由总统李在明主持，其政策主管称将公布聚焦于 AI 数据中心和物理 AI 的极其不寻常的数据。尽管宣布了重大的投资消息，但由于市场担心零部件成本上升可能抑制消费设备需求，两家公司的股价在同日均下跌超过 9%。

**背景**: 三星和 SK 海力士是全球内存芯片的主导制造商，而内存芯片是英伟达 GPU 等 AI 加速器中使用的高带宽存储器（HBM）的关键组件。“物理 AI（Physical AI）”是指将人工智能集成到物理实体（如机器人和自主系统）中，使其能够与现实物理世界进行交互。这些投资计划反映了行业更广泛的趋势，即通过指数级增加资本支出，来满足全球 AI 热潮对基础设施的巨大需求。
