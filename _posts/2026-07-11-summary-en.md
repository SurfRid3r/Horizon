Surgeons have successfully performed the world's first live animal surgeries—a minimally invasive cholecystectomy on live pigs—using a remotely controlled Unitree G1 humanoid robot. The preclinical trial results were published in the journal Nature, marking the first time a general-purpose humanoid robot has been used for live surgery. This breakthrough demonstrates that low-cost, general-purpose humanoid robots can perform complex surgical procedures, challenging the dominance of expensive specialized systems like the da Vinci surgical robot. The affordable price point—$13,500 for the base model and approximately $67,000 with dexterous hands—could make robotic surgery accessible in resource-limited settings such as rural areas, battlefields, and even space missions. The Unitree G1 stands approximately 1.5 meters tall and weighs about 27 kilograms, with a compact footprint suitable for operating rooms. Researchers from UC San Diego noted that the robot's 23-43 joint motors provide flexibility surpassing conventional robotic platforms, enabling the precise manipulation needed for surgical procedures.

The WgpSec security team introduced the Alkaid agent framework, which uses a minimalist blackboard architecture (Fact/Intent/Goal primitives) combined with an OODA (Observe, Orient, Decide, Act) scheduling loop to achieve fully autonomous, end-to-end offensive security operations. The system reportedly achieved a 54/54 capture rate in the Tencent Cloud Challenge, operating without reliance on RAG, MCP, or fine-tuning. This represents a shift from "human directing AI" to "AI autonomous problem-solving," addressing persistent LLM flaws like state amnesia and hallucination through architectural design rather than external tooling. It unifies both "achievement mode" (e.g., capturing flags) and "coverage mode" (e.g., exhaustive vulnerability discovery), offering a robust paradigm for the future of autonomous red teaming. The framework relies on three blackboard primitives (Fact, Intent, Goal) and a self-emergence mechanism to naturally grow attack chains without external dependencies. It also introduces mathematical termination criteria to prevent the LLM from self-deception and ensure comprehensive attack coverage.

## [Six U-Boot Vulnerabilities Enable Pre-Boot Code Execution](https://www.bleepingcomputer.com/news/security/new-u-boot-flaws-could-enable-stealthy-firmware-attacks/) ⭐️ 8.0/10

Firmware security firm Binarly disclosed six vulnerabilities in U-Boot's FIT (Flat Image Tree) signature verification code, with two enabling arbitrary code execution and four causing device crashes. The flaws trace back to U-Boot version 2013.07, affecting over 50 stable releases and numerous downstream vendor branches. These vulnerabilities allow attackers to execute malicious code before the OS and security software load, potentially disabling firmware security features, altering the boot process, or implanting persistent firmware malware. The impact is especially severe for BMC-equipped systems that support remote firmware updates, as exploitation requires no physical access, and patching depends on individual hardware vendors distributing firmware updates. Binarly has submitted patches to U-Boot maintainers and they have been accepted, but fixes will only reach end users after each hardware vendor integrates them into firmware updates. Legacy and end-of-life devices may never receive patches, leaving them permanently vulnerable.

telegram · zaihuapd · Jul 11, 08:32

**Background**: U-Boot is a widely used open-source bootloader for embedded devices that initializes hardware and loads the operating system. FIT (Flat Image Tree) is an image format used by U-Boot that supports signature verification to ensure only trusted firmware images are loaded during boot. BMC (Baseboard Management Controller) is a specialized service processor embedded on server motherboards that enables remote management, including firmware updates, independent of the host OS.
